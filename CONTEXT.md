# Code Carton Website

The public home of Code Carton and the products and writing created through it.

## Language

**Code Carton**:
Jordan Calhoun's maker studio and the primary identity that organizes the website. Jordan is presented as its author rather than as a separate personal brand.
_Avoid_: Personal portfolio, anonymous company

**Developer Log**:
Code Carton's unified writing section for release notes, technical findings, product announcements, and behind-the-scenes posts.
_Avoid_: Change Log, separate product blogs

**Product**:
An active, publicly supported app or open-source tool made by Code Carton. Commercial model does not determine whether work belongs in the primary product portfolio.
_Avoid_: Commercial release, open-source section
